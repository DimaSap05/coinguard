# CoinGuard

Учебное приложение Flutter для просмотра подписок и среднемесячных расходов.
Лабораторная № 4: Dio → репозиторий → HomeBloc → BlocBuilder.
Лабораторная № 5: отдельный GET `/subscriptions/{id}` → репозиторий → ContentBloc → детальный экран.

## Запуск

После клонирования проекта установите зависимости командой `flutter pub get`.
Для запуска нужны Flutter SDK и Python 3.

1. В первом терминале из корня проекта запустите сервер (Python 3, без сторонних пакетов):

   ```powershell
   python api/server.py
   ```

   Если Python установлен через Windows Launcher, используйте `py -3 api/server.py`.
   Оставьте этот терминал открытым. Проверка: `http://localhost:8080/subscriptions`.

2. Во втором терминале запустите Flutter:

   ```powershell
   flutter run -d chrome
   ```

   Для Android-эмулятора выберите его идентификатор из `flutter devices` и выполните
   `flutter run -d <идентификатор>`. По умолчанию Android обращается к `10.0.2.2:8080`
   (адрес компьютера из стандартного Android Emulator), браузер и desktop — к `localhost:8080`.

Для физического Android-устройства по USB можно выполнить `adb reverse tcp:8080 tcp:8080`, затем:

```powershell
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8080
```

Для подключения телефона по Wi-Fi сервер можно запустить с `--host 0.0.0.0`,
а в `API_BASE_URL` указать LAN IP компьютера. Понадобятся одна сеть и доступ через брандмауэр.
Учебный сервер не имеет авторизации, не предназначен для публикации и реальных финансовых данных.
HTTP разрешен в Android debug/profile; для release требуется HTTPS API.
iOS на этой Windows-машине не проверялся; для локального HTTP потребуется настройка ATS.

## Контракт API

`GET /subscriptions` возвращает объект с массивом `data`. Пример записи:

```json
{
  "data": [{
    "id": "sub_1",
    "name": "Яндекс Плюс",
    "price": 399.0,
    "period": "month",
    "nextBillingDate": "2026-11-02",
    "categoryColor": 4294951175,
    "categoryName": "Развлечения",
    "description": "Семейная подписка на Музыку и Кинопоиск."
  }]
}
```

Период — `month` или `year`, цвет — целое ARGB, дата — ISO 8601.
`description` может отсутствовать или быть null. В серверном файле `api/subscriptions.json`
вместо конкретной даты задается `billingInDays`: сервер вычисляет дату относительно дня запроса.
Тарифы и история являются демонстрационными.

Это собственный HTTP API, что допускается методичкой. Клиент не подменяет HTTP локальными
данными: при недоступном сервере показывает ошибку и кнопку «Повторить».

## Проверка лабораторной

- При работающем сервере появляются три подписки и сумма 2728 ₽.
- Откройте каждую карточку: детальный экран выполняет отдельный GET `/subscriptions/{id}`,
  даже если список уже загружен. Сервер возвращает один объект в поле `data`.
- Прямой маршрут `/content/sub_1` загружает выбранную подписку через API.
- `/content/unknown` показывает «Подписка не найдена» после HTTP 404.
- Ошибка соединения на детальном экране показывает кнопку «Повторить».
- Каждый детальный экран получает собственный ContentBloc через GetIt factory и закрывает его при уходе.
- Кнопка обновления повторяет запрос. Остановка сервера и обновление показывают ошибку;
  после запуска сервера «Повторить» восстанавливает список.
- Пустой массив `[]` в серверном файле дает сумму 0 и сообщение об отсутствии подписок.
- В консоли Flutter видны HTTP-запросы и состояния BLoC через Talker;
  в консоли Python — запросы к серверу.

После изменения модели перегенерируйте сериализацию:

```powershell
dart run build_runner build -d
flutter analyze
flutter test
```

Если Windows SDK не распознает корневой пакет в кириллическом пути или не может
создать AOT-файл генератора, предусмотрен JIT-запуск установленного генератора:

```powershell
powershell -ExecutionPolicy Bypass -File tool/generate.ps1
```

Интеграционный тест с настоящим API запускается отдельно при работающем сервере:

```powershell
flutter test --dart-define=RUN_API_TESTS=true
```

Репозиторий хранит последний успешно разобранный ответ в памяти. База данных,
уведомления и реальная отмена подписок в лабораторную № 4 не входят.
